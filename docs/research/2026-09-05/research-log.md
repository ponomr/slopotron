# Журнал исследования и проверки

Дата: 2026-09-05. Объект: Slopotron upstream `113e40139600a2e0dd2b8c782a8f28181b4f38a9`.

## Постановка

Пользователь запросил последнюю версию скилла, глубокое исследование сетевых источников с приоритетом русского языка и фиксацию ключевых находок в документации. Принятый формат — Markdown рядом с проектом. Успех этой работы: обновлённый checkout, проверяемый аудит, первичные источники с ограничениями и план улучшений. Внедрение новых правил и доказательство их эффективности — следующий этап, а не часть выполненного эксперимента.

План записан в `tasks/todo.md` рабочего ai-hub. Инструмент `update_plan` в текущем окружении не предоставлен. Исследование проведено в текущей задаче; параллельно изучались русские корпуса и общая лингвистика. Координатор проверял исходный скилл, ограничения детекции и ключевые источники обеих линий. Все изменения документации сведены координатором.

Дополнительные найденные работы о lexical overrepresentation и excess vocabulary не добавлены в реестр: временной сдвиг и зависимость от корпуса уже представлены прямыми источниками; расширение библиографии не изменяло рекомендации.

Причина завершения поиска: основные разделы имеют первичное подтверждение либо явно описанный пробел; контраргументы к универсальным запретам и полной недетектируемости учтены. Для решения оставшихся вопросов нужен новый эксперимент на Slopotron, а не ещё один общий список признаков из сети.

## Проверка ключевых утверждений

- Сверено содержимое свежего upstream с прежней веткой: текстовых различий нет; новая верхушка истории включает принятый PR кавычек.
- CoAT: проверены места о перекрытии распределений и зависимости richness от задачи.
- MULTITuDE: русский присутствует в таблицах; неанглийский агрегат не назван русской метрикой.
- Russell: прочитаны ограничения и процедура отбора экспертов. Высокая точность не обобщена на всех пользователей LLM.
- Guo: проверены разнонаправленные изменения разнообразия и ограничение анализа этапов обучения задачей историй.
- Богинская: сопоставлен извлечённый текст опубликованных колонок «до/после»; новый количественный результат описан как наблюдение по этой паре, без обвинения в недостоверности полного исследования.
- WALS и Розенталь: проверены конкретные записи о SVO и заглавной после двоеточия.
- Статические размеры скилла вычислены программно. Эмпирические проценты детекции не воспроизводились и не используются как собственный результат.

## Ограничения доступа и проверки

Грамота.ру вернула HTTP 403 для страниц прямой речи и поиска парцелляции. Для правила о заглавной использован доступный текст Розенталя. PDF академического справочника на `orfo.ruslang.ru` не открылся через web-инструмент; его содержимое не считается прочитанным.

Страница Nature Human Behaviour для статьи о linguistic diversity не открылась; проверены метаданные публикации и открытая авторская версия. Страница Nature с SynthID-Text отдаёт редирект с параметром cookies, но основной текст и ограничения доступны и прочитаны.

Скриншот страницы русского PDF с примером GigaChat не получен: инструмент вернул `Cache miss`. Доступен и проверен текстовый слой. Визуальная верификация таблицы не заявляется. Полные корпуса и исходные экспериментальные данные статей не скачивались, исследования авторов не реплицировались.

Доставка — Markdown, поэтому выполнена структурная проверка: локальные ссылки, целевые строки скилла, согласованность версии и чисел, таблицы и отсутствие заявлений о несуществующих прогонах. PDF/DOCX и визуальный рендер отчёта не создавались.

Исследовательские линии агентов завершились и были использованы после проверки ключевых источников координатором. Дополнительное независимое ревью готовых документов не состоялось: оба агента вернули `You've hit your usage limit`. Повторные запуски не выполнялись; финальное содержательное ревью проведено координатором. Это ограничение контроля, а не отсутствующее основное исследование.

## Как воспроизвести проверку версии

В локальном репозитории:

```bash
git fetch upstream
git rev-parse upstream/main
git show -s --format='%H %aI %s' upstream/main
git diff upstream/main -- .claude/skills/slopotron/SKILL.md .claude/commands/slopotron.md
```

Отдельно проверить, что установленный симлинк указывает на ожидаемый checkout. После будущего обновления анализ относится к зафиксированному SHA, пока строки и выводы не пересмотрены. В рамках этой работы изменения правил не публиковались и новая версия модели не запускалась.
